# 假期跨方式客流校正与发布

归集多运输方式假期客流，处理口径、修订、勘误和历史发布。

## 参与方与事实

主要参与方包括交通运行分析人员、铁路数据提供方、公路数据提供方、水路和民航数据提供方、发布审核人员。领域资料记录以下已经确认的事实：

- 2026年中秋三天跨区域人员流动总量为64316.1万人次
- 统计同时覆盖铁路、公路、水路和民航
- 公路数据进一步区分营业性客运与非营业性小客车出行

## 业务约束

- 来源批次
- 统计口径版本
- 跨方式汇总
- 勘误发布
- 历史结果解释

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/mobility_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
